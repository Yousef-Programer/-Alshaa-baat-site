# Alshaa'bat - Maintenance and Supply Website

موقع إلكتروني لمؤسسة الشعبات للتجارة، متخصصة في توريد المعدات الصناعية، الصيانة، وقطع الغيار في المملكة العربية السعودية.

A portfolio website for **Al Shaahat Trading Establishment**, specialized in industrial equipment supply, maintenance, and spare parts in Saudi Arabia.

---

## 🌟 المميزات | Features

- ✅ تصميم متجاوب يعمل على جميع الأجهزة (Responsive Design)
- ✅ واجهة عصرية وأنيقة
- ✅ أقسام متعددة: عن الشركة، الأعمال، التواصل
- ✅ صفحات منفصلة للخدمات (التوريد، الصيانة، قطع الغيار)
- ✅ إمكانية تحميل ملف التعريف بالشركة (PDF)

---

## 🛠️ التقنيات المستخدمة | Technologies Used

- **HTML5** - هيكلة الموقع
- **CSS3** - التنسيق والتصميم
- **Google Fonts** - خطوط Poppins و Tajawal
- **SVG** - الأيقونات والرسومات

## 🚀 كيفية التشغيل | How to Run

### الطريقة 1: محلياً (Local)
1. حمّل المشروع أو استنسخه:
   ```bash
   git clone https://github.com/YOUR-USERNAME/alshaa-maintenance-supply.git
   ```
2. افتح ملف `index.html` في المتصفح

### الطريقة 2: عبر Live Server (VS Code)
1. افتح المشروع في VS Code
2. اضغط بزر الماوس الأيمن على `index.html`
3. اختر **Open with Live Server**
